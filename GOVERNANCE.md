# Organization governance

## Teams

- **Engineering:** implementation, code review, testing, and technical maintenance.
- **Product Delivery:** intake, scope, acceptance criteria, client evidence, and handover.
- **Security and Release:** privacy/security review, release gates, rollback, and incident coordination.

Team membership does not replace repository-specific least privilege. Administrative access is granted only when the operating responsibility requires it.

## Projects

The organization delivery project is used for cross-product milestones and evidence states. Product repositories remain the source of truth for code, and release documents remain the source of truth for readiness.

## Evidence vocabulary

Use explicit states such as implemented, locally verified, hosted verified, deployed staging verified, production verified, blocked, and not started. Do not translate a passing build into a deployment claim.
